# Security policy

## Reporting a vulnerability

Email security@secvalis.eu. Please do not open a public issue for a vulnerability.
Our contact details and disclosure policy are also published in
https://secvalis.eu/.well-known/security.txt.

## Advisories

Security advisories for the agent are published in this repository's
[Security Advisories](https://github.com/secvalis/secvalis/security/advisories) and on
https://secvalis.eu/en/trust.

A version with a known problem is added to [`REVOKED`](REVOKED) on `main`. Its signature still
verifies, so always check `REVOKED` before running a release.
